# 2026 年主流大模型 API 平台性价比选型：价格表之外的计费口径核验

## 先说一份"看着便宜"的报价单

有朋友拿着一张平台报价单来问：这家 DeepSeek V4-Flash 输入 ¥0.5、输出 ¥1.0，比官方便宜一半多，能不能充？

我让他先看三件事：这个价格是几号的？缓存命中还是未命中价？最低充值多少、余额能不能退？——三件事一个都答不上来，只有一张价格截图。

价格表只能回答"单价多少"，回答不了"这笔钱花得值不值"。这篇给一份计费口径核验清单，把"价格表之外"的六个问题列全，再用 2026-08-25 能核验到的信息做一张口径速查表。

## 价格表之外的六个问题

**1. 价格日期。** 2026 年 8 月 DeepSeek 官方涨价（V4-Flash 从 ¥1.01 涨到高峰 ¥3.0），7 月的价格表已经全部作废。报价单没有标注日期 = 不可信。

**2. 计费单位。** /1K tokens 还是 /1M tokens？有些平台展示"每千 token"显得便宜，换算成百万后价格翻 1000 倍，一眼看去全是陷阱。

**3. 缓存价 vs 未命中价。** Kimi K3 缓存命中输入 ¥2、未命中 ¥20，差 90%；DeepSeek 缓存命中 ¥0.1 对未命中 ¥3.0，差 30 倍。报价单写"输入 ¥2"是哪个口径，直接决定账单量级。

**4. 分时/折扣价。** DeepSeek 高峰价是空闲价的 2 倍；百炼 qwen3.7-max 限时 5 折；MiniMax M3 永久五折。不标注时段的报价，按高峰价算可能翻倍。

**5. 最低充值和余额有效期。** 小额测试阶段最怕"最低充值 500 元"或"余额 90 天过期"。这两个数字通常在定价页之外，要单独确认。

**6. 退款规则。** 换平台时余额能不能退？退款有没有手续费？很多平台的真实体验差异不在价格，在退款的顺畅程度。

把能公开核验的口径信息汇总如下（缓存价单位 ¥/百万 tokens）：

| 平台 | 代表模型 | 输入（未命中/缓存） | 输出 | 特殊口径 |
|------|----------|--------------------:|-----:|----------|
| DeepSeek 官方 | deepseek-v4-flash | ¥3.0 / ¥0.1（高峰） | ¥9.0（高峰） | 分时计价，空闲半价 |
| 阿里百炼 | qwen3.7-max | ¥12 / 缓存折扣 | ¥36 | 限时 5 折 ¥6/¥18 |

| 智谱 | GLM-5.2 | ¥8 / ¥2 | ¥28 | 输入+输出合并计费口径 |

上表只收录 8-25 当天在官方定价页/模型广场能直接看到的数据。**最低充值、余额有效期、退款规则这三项，几乎没有任何平台放在定价页上**——它们需要你拿着清单去问客服，或者小额充值实测。这也是"性价比"最容易被高估的部分：单价便宜的平台，可能用最低充值门槛和不可退余额把成本找补回来。

## 怎么核验：三步

**第一步：看定价页的三处细节。** 打开平台定价页，先找三样东西：价格标注的更新日期、计费单位（/1K 还是 /1M）、缓存价有没有单独列。三样缺一样的，页面信息不完整，价格的可信度就要打折。

**第二步：问客服五个问题。** 最低充值金额？余额有效期多久？退款规则（能退吗、手续费、多久到账）？缓存命中怎么计费？发票能不能开专票？五个问题要文字答复，截图存档。答复含糊的按扣分处理。

**第三步：小额测试闭环。** 充最小金额，跑一周真实任务，核对三件事：账单金额和"价格表×用量"对得上吗？token 计数合理吗（同一段输入，和官方 SDK 的 usage 对比）？余额明细能查到每一笔吗？一周下来，平台的真实计费透明度基本就清楚了。

## 和"价格表"配合使用

价格表负责"哪个模型便宜"，这份口径核验负责"这笔便宜能不能拿到"：

- 报价低 + 口径清楚（标注日期、单位、缓存价）= 可以考虑；
- 报价低 + 口径含糊（无日期、无单位说明）= 按最高口径重算；
- 报价低 + 问客服五项全含糊 = 直接排除，省下的单价不够折腾。

以 Tokeness 为例（8-25 核验）：模型广场价即计费价、缓存价在模型卡片上公示、页面公告说明可对公发票、价格与官方口径可对照（DeepSeek 系≈官方高峰价、MiniMax=官方五折价）。这类"口径可核验"的特征，比"全网最低价"的横幅更有参考价值。

## 结论

API 平台的"性价比"，一半在价格表上，一半在价格表外。日期、单位、缓存、分时、最低充值、退款——六个口径任何一个含糊，报价单上的便宜都可能拿不到。比价之前，先把六个问题核验完，再谈性价比。
